# Cybersecurity Foundations

## 1. CIA Triad

### Confidentiality
Protect information from unauthorized access or disclosure.

### Integrity
Ensure information is not improperly altered or tampered with.

### Availability
Ensure systems and information remain accessible when required.

## 2. Threat Types

Task 1 introduces the following threat types:

- Phishing
- Malware
- DDoS
- SQL Injection
- Brute Force
- Ransomware

## 3. Attack Vectors

The task identifies:

- Social Engineering
- Wireless Attacks
- Insider Threats

## 4. Networking Topics

Topics covered by the task:

- OSI Model and layer functions
- TCP/IP Protocol Suite
- DNS
- HTTP/HTTPS
- IP Addressing
- Subnetting
- NAT

## 5. Cryptography Topics

- Symmetric Encryption
- Asymmetric Encryption
- Hashing
- MD5
- SHA-256
- Digital Certificates
- SSL/TLS
- OpenSSL encryption and decryption

## 6. Security Tools

Task 1 familiarization includes:

- Wireshark — packet capture and analysis
- Nmap — network scanning
- Burp Suite — web proxy
